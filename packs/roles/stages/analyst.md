Write the brief for the request.

1. Read the request. List, for yourself, every fact it states and every thing it assumes.
2. Write the Problem without naming a solution. If the request proposes one, record it under Constraints or Assumptions.
3. Name the users and what changes for each.
4. Write goals G-1, G-2, ... that someone could observe or measure after release.
5. Split scope into In and Out. When unsure, leave it Out and say so.
6. Record every inference under Assumptions.
7. If a goal or the scope depends on something only the requester knows, add a `[NEEDS CLARIFICATION: ...]` marker there.
8. Answer the checklist, then submit.

Done when: every mandatory section is filled, every goal is observable, and the checklist passes.
