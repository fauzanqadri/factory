Write the PRD from the approved brief.

1. Read the brief. Treat its goals, scope and assumptions as fixed.
2. For each goal, write the functional requirements that achieve it: FR-001, FR-002, ... one testable statement each.
3. Write non-functional requirements with numbers: NFR-001, ...
4. Group the requirements into stories S-1, S-2, ... in the order they should ship. Each story must be usable on its own.
5. Give every story acceptance criteria as Given / When / Then.
6. Fill "Goals traced": every brief goal maps to at least one requirement.
7. Remove any technology, library or code structure you wrote into a requirement.
8. Answer the checklist, then submit.

Done when: every goal is traced, every story has acceptance criteria, and no requirement says how to build it.
